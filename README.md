# Surreal Land

사진·영상 고르기(또는 AI로 만들기) → 이펙트 레이어 → 최종 아트워크(PNG + MP4)까지 한 화면에서 만드는 웹 툴.
@mezotes 피드 854개를 분석해 나온 기법들을 레이어로 조합합니다 ([docs/mezotes-analysis.md](docs/mezotes-analysis.md)).

## 실행

```bash
npm install
npm run dev
```

http://localhost:5178 을 최신 Chrome에서 여세요. 포트가 사용 중이면 Vite가 다음 번호(5179…)로 엽니다. 영상 인코딩에 WebCodecs가 필요합니다.

### Higgsfield로 사진 만들기 (선택)

1. https://open.higgsfield.ai 에서 로그인 → **Build with Code** → API keys(https://open.higgsfield.ai/api-keys)에서 키를 만들고 복사합니다.
2. 둘 중 하나:
   - 툴 왼쪽 **AI 생성** 도구의 맨 위 칸에 키를 그대로 붙여넣고 저장합니다 (이 브라우저에만 저장).
   - `.env.local.example`을 `.env.local`로 복사하고 `HF_API_KEY=<키>`를 채운 뒤 서버를 다시 켭니다.
3. 키는 브라우저에서 Higgsfield로 바로 가지 않고, 로컬 개발 서버(`server/higgsfield.ts`)를 거쳐서만 전달됩니다.

모델: Soul 2, Z-Image Turbo, Marketing Studio Image(참고 사진 편집), Grok Imagine 2.0(참고 사진 편집). 완성된 사진은 자동으로 갤러리에 들어가고, 원하면 바로 베이스가 됩니다.

### 구글 나노바나나로 만들기·고치기 (선택)

1. https://aistudio.google.com/apikey 에서 API 키를 만듭니다 (사용료는 그 Google 계정에 청구).
2. 둘 중 하나:
   - 툴 왼쪽 **AI 생성 → 나노바나나 (Google)** 맨 위 칸에 키를 붙여넣고 저장 (이 브라우저에만 저장).
   - `.env.local`에 `GEMINI_API_KEY=<키>`를 넣고 서버를 다시 켭니다.
3. 키는 로컬 개발 서버(`server/gemini.ts`)를 거쳐서만 Google로 가요.

- **새로 만들기**: 장면 레시피·주제·프롬프트로 베이스 사진 생성. 참고 사진을 최대 6장까지 함께 보낼 수 있어요.
- **사진 고치기**: 고를 사진(또는 효과가 적용된 **지금 캔버스**)을 글로 고쳐요. 하늘 찢기·땅 띄우기·녹아내리기·액체 크롬·하늘 비친 웅덩이·빛의 문·하늘 속 다른 세계·회로로 덮기·유리 몸·진짜 사진처럼 합치기 같은 지시문이 준비돼 있어요.
- 모델: Nano Banana 2.1(최신), Nano Banana 2, Nano Banana Pro, Nano Banana 2 Lite, Nano Banana(구버전). 새 모델이 나오면 “다른 모델 이름 직접 쓰기”에 이름만 넣으면 돼요.
- Google의 Interactions API(`/v1beta/interactions`)를 쓰고, 그걸 지원하지 않는 모델이면 `generateContent`로 다시 시도해요.
- **API 없이 구독으로 쓰기**: Gemini API는 Gemini 앱 구독(Google AI Pro 등)과 별도로 결제해야 하고, 무료 등급에는 이미지 모델 한도가 없어요. 대신 패널의 “사진 복사 / 프롬프트 복사” → Gemini 앱이나 Higgsfield 웹의 나노바나나에 붙여넣고 생성 → 결과 이미지를 복사해서 이 창에서 **⌘V**(또는 다운로드해서 끌어놓기)로 가져올 수 있어요. ⌘V 붙여넣기는 어느 화면에서나 돼요.

## 피드 프리셋 854

왼쪽 **프리셋** 도구의 **@mezotes 피드 프리셋 854**를 누르면 @mezotes 게시물 854개를 하나씩 보고 만든 프리셋이 열립니다.

- 프리셋마다 **AI 원본 프롬프트**(Higgsfield에 넣을 장면 설명) + **룩**(이펙트 레이어 묶음, 63종 중 하나) + **참고 게시물 링크**가 들어 있어요.
- **적용**: 레이어를 깔고 프롬프트를 AI 생성 칸에 넣어요. **레이어**/**프롬프트**만 따로 적용할 수도 있어요.
- 검색(제목·프롬프트·룩·번호), 시기 필터(풍경 합성·데이터 / 회로 콜라주 / 유리 몸 / 초기 AI 초상), 룩 필터.
- 데이터: `src/library/sheets/*.ts`(게시물 순서대로 `[제목, 룩, 프롬프트]`), `src/library/posts.json`(게시물 링크), 룩 정의는 `src/engine/looks.ts`.
- 원본 이미지는 저장하지 않았고, 실존 인물을 패러디한 게시물은 일반 인물 묘사로 바꿨어요.

## 화면 구성

```
┌ 상단: 되돌리기 · 다시 · 전체 섞기 · 저장 · 열기 · 사용법 · [내보내기]
├ 왼쪽 도구 레일(1–5)   ├ 도구 패널        ├ 캔버스 + 타임라인     ├ 오른쪽: 고른 것의 설정
│ 사진 / AI 생성 / 프리셋 / 효과 / 선택     │ (도구를 다시 누르면 패널이 접혀요)
```

오른쪽은 지금 고른 것에 따라 바뀝니다: 효과 레이어 → 효과 설정, 저장된 선택 → 선택 다듬기, 아무것도 없으면 → 4단계 안내와 단축키.

## 작업 흐름

1. **사진·영상**: 올리기(창 어디에나 끌어놓아도 됨) / 샘플 / AI 생성. 크기(4:5·3:4·1:1·9:16·16:9)와 구도를 정해요. 다른 사진·영상은 합성 효과의 재료가 됩니다.
   - **영상**(MP4·MOV·WebM)을 베이스로 고르면 타임라인 길이가 영상 길이에 맞춰지고, 미리보기·MP4 내보내기 모두 영상 프레임 위에 효과가 얹혀요. 소리는 빠져요. 움직이는 물체는 선택한 뒤 **따라가기**를 누르면 마스크가 물체를 따라가요.
2. **선택** — 사진에서 특정 물체 지정
   - **클릭**: 캔버스에서 물체를 누르면 “물체 1”처럼 이름 붙은 선택이 저장돼요. `Shift`+클릭은 지금 선택에 더하기, `Option`+클릭은 빼기.
   - **브러시**: 드래그로 칠하고 `Option`+드래그로 지우기. **네모 / 원**: 드래그한 상자(타원)를 그대로 선택. `Shift`+드래그는 더하기, `Option`+드래그는 빼기. **색**: 클릭한 색과 비슷한 곳 전부.
   - **한 번에 선택**: 하늘 / 사람 / 밝은 곳 / 어두운 곳 / 빈 선택.
   - 선택마다 이름·색을 바꾸고, 넓히기·좁히기·가장자리 부드럽게·반전·**계단 경계**(픽셀 블록처럼 각지게)로 다듬어요.
   - 캔버스 아래 막대: **효과 넣기**(그 물체에만) · **흐르게**(폭포·강·구름 시네마그래프) · **오려서 띄우기** · **따라가기**(영상) · 반전 · 삭제.
   - **영상에서 따라가기 (로토스코프)**: 베이스가 영상이면, 지금 보이는 프레임에서 고른 물체(또는 사람)를 영상 앞뒤로 따라가며 프레임마다 마스크를 만들어요. 그 물체에 넣은 효과·오려서 띄우기·흐르게가 움직이는 물체를 따라가요. 정밀도는 초당 8/12/24장, 4초 영상(초당 12장) 기준 약 13초 걸려요. 추적한 마스크는 새로고침하면 사라지니 프로젝트 파일로 저장해 두세요.
   - 클릭 선택과 “사람”은 MediaPipe 모델을 처음 쓸 때 인터넷에서 받아요(몇 초). 선택은 사진의 구도 기준이라, 구도를 먼저 정하고 고르세요.
3. **효과**: “효과 추가”를 누르면 66종을 **내 사진에 적용한 미리보기**로 보여줘요(분류·검색). 물체에서 열면 미리보기도 그 물체에만 적용돼요. 레이어 목록에는 각 효과가 어디에 들어가는지(전체 / ● 물체 1 / 칠한 곳…)가 보여요.
4. **오른쪽 효과 설정**
   - **적용 대상**: 화면 전체 / 선택한 물체 / 모양(네모·원·그라디언트) / 직접 칠하기 + 가장자리 흐림, 반대로(밖에만). 물체 칩에 마우스를 올리면 캔버스에 위치가 보여요.
   - 효과 값(묶음별로 접기), 합성(진하기·섞는 방식 13가지), 등장 시간(등장·퇴장·페이드).
   - 순서 이동, 복제, 이 레이어만 섞기, 기본값, 삭제.
5. **프리셋**: 레시피 38개(내 사진 미리보기)와 @mezotes 피드 프리셋 854. 지금 효과를 통째로 바꿔요(⌘Z로 되돌리기). 저장된 선택은 그대로 남아요.
6. **내보내기**: PNG(현재 프레임, 1×/2×), MP4(H.264, 프레임 단위 오프라인 렌더). **저장/열기**는 레이어·선택·사진을 JSON 파일 하나로.

단축키: `1`–`5` 도구, `Space` 재생, `⌘Z`/`⇧⌘Z` 되돌리기/다시, `⌘D` 복제, `Delete` 레이어·선택 삭제, `Esc` 고른 것 해제, 방향키 영역 미세 이동(`Shift` 크게), 모서리 `Shift`+드래그 비율 고정.

## 구조

- `src/engine/renderer.ts`: 프레임 렌더러. 레이어마다 시간 구간·페이드·진하기·섞는 방식·적용 범위를 처리합니다. ‘overlay’ 효과는 투명 레이어에 그린 뒤 합성합니다.
- `src/engine/effects/*`: 이펙트 정의. `params`만 선언하면 인스펙터 UI가 자동으로 생깁니다.
- `src/engine/masks.ts`, `src/engine/select.ts`: 선택·마스크(저장 형식, 브러시, 넓히기/좁히기, 하늘·밝기·색·MediaPipe 사람/물체 선택).
- `src/engine/presets.ts`: 레시피와 랜덤 조합.
- `src/App.tsx`: 화면 배치와 상태. 도구 패널은 `src/ui/*Panel.tsx`, 캔버스는 `Stage.tsx`, 효과 고르기는 `EffectGallery.tsx`, 오른쪽은 `Inspector.tsx` / `SelectionInspector.tsx` / `Guide.tsx`.
- `src/engine/export.ts`: PNG·MP4 내보내기(mediabunny + WebCodecs).
- `server/higgsfield.ts`: Higgsfield API 로컬 프록시(Vite 플러그인).
- `src/ui/scenes.ts`: AI 생성용 장면 프롬프트(피드 분석 기반).

레이어 구성과 설정은 브라우저에 자동 저장되지만, 사진까지 보관하려면 **저장** 버튼으로 프로젝트 파일을 만드세요.
