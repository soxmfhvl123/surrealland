# @mezotes 피드 분석 (854개 게시물, 2026-10-21 기준)

Instagram 프로필 그리드 전체(최신 → 가장 오래된 순)를 썸네일 시트로 훑어 정리한 메모입니다.
이미지는 저장하지 않았고, 기법과 장면 유형만 기록했습니다.

## 시기별 흐름

| 구간 (최신=0) | 성격 | 대표 기법 |
|---|---|---|
| 0 – 약 120 | **풍경 합성 + 데이터** (지금 스타일) | 떠있는 하늘 창·물 반사, 잘려 떠오른 땅, 녹아내리는 건물·폭포, 거대한 코드 화면, 추적 박스·라벨, 흩어진 하늘 조각, 아치·문 포털, 원형 터널·작은 행성, 소용돌이, 스캔라인 지형, 콘덴스드 대문자 커버 |
| 약 120 – 330 | **회로·사이버 콜라주** | 회로기판과 꽃·동물·얼굴 합성, 레트로 OS 창·터미널 콜라주, CRT 모니터 더미, 케이블, 크롬·글리터 몸, 포일로 감싼 차, 무지개 포인트 |
| 약 330 – 480 | **유리 몸·그로테스크 패션** | 투명한 유리 인체, 번들거리는 피부, 보석 얼굴, 매거진 레이아웃, 리소 프린트(2색 망점), 얼굴 반복(잔상) |
| 약 480 – 854 | **초기 AI 초상·초현실** | 그로테스크 캐릭터, 오컬트, 패러디 초상, 빈티지 필름 톤, 포스터 타이포 |

## AI 원본 생성에 쓰는 장면 유형

이펙트로 만들 수 없는 것(회로 생명체, 유리 인체, 크롬 피부, 포일 감싼 차 등)은 원본 사진 단계에서 만들어야 합니다.
그래서 생성 패널의 “장면 레시피”를 위 시기별 대표 장면으로 구성했습니다 (`src/ui/scenes.ts`).

## 세부 분석: 최근 게시물 슬라이드 단위 (2026-10-21)

최근 게시물 9개(캐러셀 슬라이드 10–20장씩, 대부분 10초 AI 영상)를 한 장씩, 영상은 여러 시점으로 확인했습니다. 연령 제한 게시물 2개는 로그인이 필요해 건너뛰었습니다.
요즘 작업은 **AI 영상 + 2D 합성**이 중심이고, 한 게시물이 한 가지 테마(액체 크롬, 위성 지도, 기계 테라리움, 밤 플래시 등)를 여러 변주로 보여줍니다.

| 피드에서 본 것 | 새 이펙트 / 기능 |
|---|---|
| 하늘이 종이처럼 찢겨 불타는 가장자리, 안에 다른 하늘 | 찢긴 하늘 |
| 정원·길 한가운데 하얗게 빛나는 문, 안에 사람 실루엣 | 빛의 문 |
| 구름 천장에서 내려오는 한 줄기 빛이 사람을 비춤 | 빛기둥 |
| 잔디 위 검은 물웅덩이·수은 웅덩이가 하늘을 비춤 | 반사 웅덩이 (검은 물/맑은 물/수은) |
| 유리 구슬 속에 거꾸로 굴절된 풍경 | 유리 구슬 |
| 잡동사니 장면 위 흰 빈 카드 + 빨강·초록 점을 잇는 연결망 | 빈 카드, 점 연결망 |
| 위성 지도에 확대 상자·좌표·가는 연결선 | 확대 인셋 |
| 같은 풍경의 네모 조각이 다른 자리에 붙어 툭툭 바뀜 | 패치 콜라주 |
| 산을 여러 칸으로 나눠 배율이 다르게 어긋남, 세 풍경을 한 화면에 | 분할 콜라주 |
| 방의 벽·천장을 하늘·바다로 갈아끼운 **계단처럼 각진 경계** | 사진 채우기(계단 경계), 선택 “계단 경계” |
| 들판에 선 빨간 3D 나선 튜브, 데이터 화면 위 크롬 조각 나선 | 3D 나선 |
| 무지개 막대·히스토그램·파형·작은 썸네일이 빼곡한 검은 대시보드 | 데이터 대시보드 |
| 터미널 창 아래로 분홍·파랑 빛줄기가 흘러내림 | 빛 흘러내림 |
| 건물·계단·사람이 액체 크롬으로 덮임 | 액체 크롬 |
| 카메라 화면의 노란 십자선·ISO·REC 표시 | 뷰파인더 |
| 밤에 정면 플래시를 터뜨린 듯한 인물·사물 | 다이렉트 플래시 |
| 성당이 점점 무너져 폭포가 되는 영상, 흐르는 구름·물 | (기존) 흐르게 하기, 픽셀 스트레치 + 영상 업로드 |

AI 영상 위에 효과를 얹을 수 있도록 **영상 업로드**(MP4·MOV·WebM)를 넣었습니다.
